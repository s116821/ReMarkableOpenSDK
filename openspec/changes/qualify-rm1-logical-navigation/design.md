cannot satisfy these gates.

## Qualification and authority

Qualification needs an own backed-up disposable notebook/PDF fixture, reviewed
RM1 model/runtime/input profile and separate logical-to-physical orientation
mapping. Revalidate actual source, intended adjacent target and complete order
before dispatch; refuse stale ownership, profile or orientation. Issue at most
one supported gesture, never a blind retry. Already-target requires no input.
Completion needs the intended native target, unchanged expected order and
attributed fresh settled pixels before any consumer binding/write.

Historical capture is evidence for its named procedure, not an implementation
of that stronger freshness requirement. If an RM1 producer cannot establish the
required correspondence/settling, remain unsupported or uncertain without
consumer binding/write. Do not fabricate revisions/input epochs or turn two
matching samples into atomicity. Unchanged, uncertain and unsupported outcomes
never grant authority.

Advance notice, exact source/artifact/operator review, full own-fixture backup,
bounded independently functioning recovery and owned cleanup precede any later
idle-tablet trial. Compilation or source review is not hardware permission.
No runtime hook, input, restart, device operation or native experiment is selected.

## Smallest later read-only refresh

After existing device/operator holds are cleared and the sole operator verifies
the intended key-only USB alias, reuse the delivered collector unchanged. Local
`tools/collect_rm1_baseline.py` equals delivered
`scripts/collect_rm1_baseline.py`, SHA256
`281fb718e99904956aa13003f30dd4b7dfcf5d6517f8cb0d819413af6229a2dc`.
It needs host Python/OpenSSH only: no upload, installation or native load.
Retain its16KiB output/30-second outer bounds, fixed remote reads, strict host-key
checking and generic diagnostics. Use a fresh private host output path because a
successful observation atomically replaces the selected output file.

It refreshes model/architecture, firmware, before/after xochitl/Qt Core/PID
checks, root/home capacity and framebuffer allocation. It does not collect input
ranges, libc/provider inventory, orientation, service recovery, page identities or
pixels. Do not silently expand the command to claim those facts. A mismatch
invalidates the old profile candidate; a match still grants no native authority.
No SSH or collector execution is part of this source delta.
