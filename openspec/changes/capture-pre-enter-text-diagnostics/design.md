## Actual entry and lifetime
Enter0xb4a7f8 obtains its focused SceneTextItem owner through0xb42234 at
0xb4a80c. Its local pair is item/control at sp+0x10/+0x14. The resolver checks
the focused native ID, retains the existing root strong owner when present,
and casts to SceneTextItem. Stock retains that pair through editing and releases
it on its own exit. Capture acquires or releases no native owner.

Select only the ARM BL at0xb4a9b0 to0xb492a0 (word0xebfffa3a,
little-endian bytes3a fa ff eb). At that call, r0=participant,
r1=&stock owner pair, r2=&one-unit LF QString at sp+0x60. The ordinary
continuation is0xb4a9b4. The separate list-unindent path never reaches this site.
Do not interpose all callers of the general insertion helper or synthesize Enter.

Within this borrow, derive Scene from participant+8; require Scene+0x26c to
match the participant, Scene+0x190/+0x194 to equal the nonnull stock item/control
pair, matching item/participant IDs and admitted exact item vptrs. Use the
embedded QTextDocument at item+0x1ec. Revalidate the same correspondence before
accepting the copied candidate. Addresses and IDs serve this synchronous join;
they are not cross-invocation incarnation or ABA tokens.

## Reuse and source boundaries
Factor the private join -> copy -> join/revision recheck from
composer_scene_attachment.h into a private borrowed-read helper. Keep
composer_text_copy.h's 4096-unit result, 8192 inspection visits, exact UTF-16,
structure, surrogate, affinity/type and matching-private-Qt rules. A prepared
explicit range is read inside this borrow; no unbounded document flattening.

Attachment continues admitting only its actual typed0x1b Scene callback;
Delivery continues queued diagnostics and existing typed owner retention. Do not
call their public callback as a substitute for the new callsite admission.
The new internal bridge alone constructs the Enter borrow after profile, origin
and stock-pair checks. Public callers prepare only range, finite budget and
cancellation, then obtain copied result/refusal through bounded snapshot storage.
No public constructor accepts Scene/item/document/native owner pointers.

Prepare state outside interception. Reuse the existing claim/cancellation/
deadline/publication discipline and resident code lifetime. One prepared capture
can accept at most one invocation. Unarmed, consumed or nested capture passes
stock through. Distinct later stock Enter actions must never be deduplicated by
text/revision; another explicit preparation is a new diagnostic.

## ARM interception and exception preservation
Implement these production pieces, rather than testing a substitute C++ fake:

1. An A32 branch encoder/admission function verifies the original BL word,
   fixed origin/target, executable mappings, alignment and signed PC+8 branch
   displacement. It refuses unexpected bytes or an unavailable valid route.
2. A compiled `extern "C"` C++ shim with the original three-argument, void-return
   hard-float ABI saves original arguments in compiler-managed storage, calls a
   noexcept capture attempt and invokes the exact original function once.
3. If the compiled shim is outside the A32 BL range, reserve a non-clobbering
   executable veneer within range. A proposed A32 tail veneer is
   `ldr pc, [pc, #-4]` followed by the admitted A32 shim address. It changes no
   stack or LR, retaining the original continuation. Validate generated bytes,
   target state and loader mappings; do not overwrite an arbitrary nearby page.
4. The compiler must preserve AAPCS callee-saved registers (including platform
   r9 requirements), d8-d15 and 8-byte stack alignment. Original call arguments
   must be restored after capture. Caller-clobbered flags/registers follow the
   original ABI; audit disassembly rather than inventing a blanket preservation
   claim. Build the shim explicitly in ARM state with matching hard-float ABI.
5. Use loader-registered .ARM.exidx/.ARM.extab and compiler-generated exception
   cleanup; do not put C++ frames in unregistered copied code. The veneer is a
   tail transfer. An exception from original insertion must unwind through the
   shim to the stock caller's existing cleanup at its original continuation.
   Owned ARM throwing tests and table/disassembly inspection must prove that
   route before any native selection. A noexcept forwarding shim would violate
   this requirement and must not be used.

Capture exceptions are contained before the original call. The original call is
outside that catch. On an original exception, discard the candidate, record only
a bounded failure if possible, then rethrow without another original invocation.
After a normal original return, publication rechecks cancellation/deadline and
copies only scalar/result storage. No user callbacks, GUI signal creation, IPC,
queue wait, event pump or new native acquisition occur inside the borrow.

The precise frame layout, veneer sequence and unwind handling above are proposed
implementation choices. They are not qualified merely by this design.

## Installation and lifetime are real integration seams
An aligned four-byte store does not prove safe patching in a live process.
The installer must have an externally established quiescent install boundary:
no thread may execute the site or enter its route while code/veneer bytes and
instruction caches are changing. Specify protection transitions, rollback before
admission, instruction-cache synchronization and original-byte verification.
Never treat patch refusal as permission to rewrite unexpected code.

Implement and exercise this installer on an owned ARM executable using the same
branch encoder, veneer and shim. Production installation remains Unsupported
until the existing resident loader/runtime supplies a qualified quiescence
boundary. It must not quietly fall back to an unsafe live write or a late queued
read. This is the concrete remaining integration question, not a request for
broader text reverse engineering.

Keep shim, veneer and state resident under existing payload lifetime rules.
Cancellation closes admission; it does not unpatch code, destroy active frames,
release typed slots or permit unload. No physical unhook/reclaim path is selected
without separately established quiescence. An unarmed resident route still
forwards every stock call once.

## Composition and refusal
Require participant+0x30/+0x34/+0x44 (operation scope, IM scope, nesting) all zero;
scope-null/nesting-one refuses. Require item compose start+0x260=-1,
length+0x264=0 and virtual extension+0x268=0. Require zero Qt edit depth and no
stored preedit in the selected/boundary layouts, both with existing read checks.
Recheck join, these fields, Qt state, revisions and character count before
accepting the candidate. Refusal never suppresses or retries stock input.

GUI view+0x15e clearing does not establish native end. Retained normal binding
reset0x4c2618 clears that flag and submits end0x4ae1f8 through the old controller
before disconnecting/releasing it. Native end remains queued. The deferred close
slot's Destroy branch only deletes its closure. Direct SceneView destruction has
virtual/member cleanup whose transitive composition settlement is unresolved.
Destruction/rebinding uncertainty therefore refuses capture; do not synthesize
an end or wait for it inside an intercepted edit.

## Result semantics
The result is a frozen pre-call diagnostic plus capture/refusal and original
return/exception observations when available. A successful copy does not prove
stock mutation succeeded, semantic Submit, consumer-owned draft extent, visible
page/visit, future currentness, conditional clear or unload permission. Equal
revisions and native identity scalars cannot upgrade those claims. Preserve stock
newline/list formatting, notification and history behavior.

## Validation and delivery
Host tests exercise the shared read and capture state; existing copy tests stay
the authority for their current matrix. ARM/qemu tests link the actual compiled
shim, installer and veneer into an owned caller/original fixture with comparable
call/cleanup structure. Inspect A32 registers, branch targets and unwind tables;
exercise original exceptions across the actual route. This catches integration
defects that a fake forwarding callback cannot.

After source acceptance, Root schedules a finite disposable native check: exact
loaded profile/site, real stock pair/current root/thread correspondence, copied
pre-LF bytes, one preserved stock edit, and active-composition refusal with stock
input continuing. Folio and pen-operated OSK coverage belong to that qualification.
No runtime action follows from strict OpenSpec validation or owned ARM tests.

Keep this change active through implementation. In the same eventual PR, sync
the new canonical capability and archive only tasks supported by evidence;
explicitly record any remaining runtime boundary instead of checking it off.
