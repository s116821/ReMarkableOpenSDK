# Design
Reuse unchanged hash-installed PythonSemanticRelease, remote_identity, stage_source and verify_assets plus exact SDKPR6 rebuilt bundle. No private bump or publisher implementation. A version-free synthetic Cargo fixture is tagged in disposable bare Git using the maintained CLI; verify remote intended tag/SHA before staging/compile/package. Source/main advance must not retarget old build. Local HTTP emulates only release/asset endpoints with non-credential fixture token; no production or private account access.

Explicit draft publication stages original declared manifest/crate; injected upload failure keeps draft. Retain and hash-check original bytes, replay same verified tag/build, upload missing bytes without overwriting prior assets. Complete declared set and unchanged remote tag required before explicit maintained finalization; altered bytes refuse without reaching finalization. Host compiler/native/source safety distinctions remain. SDK source-built candidate is not upstream official dist; historical failing tool audits stay enforced. Existing independent reviewer inspects only new combined fixtures and source/provenance after actual supported hosted checks. No SDK API/runtime/device operation or production choice.
