## Decision and exact dependency

Do not select another stock opening, footer tap, or double-BODY capture merely
to claim the current gate is closed. A stock pair could measure current stock
capture timing and input-idle behavior, but cannot supply the loaded native
candidate's window/waiting identity or qualify its admission and recovery.
Main independently confirmed this boundary. No newly identified stock-only
uncertainty in this assessment warrants repeating the existing successful path.

For the selected implementation, the missing integrated measurement needs a
running native candidate with its actual waiting state and original deadlines,
followed by the selected source observations. Creating that candidate through
held8112 transfer/activation, or an equivalent renamed/rerouted workflow, remains
excluded. If that implementation is continued, the narrow dependency must be
reviewed through Main and the original platform/access path. This does not
establish that every possible native method needs that operation or impose a
ban on independently useful stock diagnostics.

No tool, fixture, timing, capture quota, admission predicate, native capability,
or service was changed. The ordinary screenshot path is not described as
process-memory-free; using the existing stock capture mechanism is distinct
from inspecting an instrumented candidate. Shutdown, native source authority,
insertion/display and production qualification remain unfinished.

Source basis: current central Docs contract; Main's current evidence pointers
and policy clarification; retained actual 092c archive/final selection, 57ee
independent timing assessment, c684 action log/images, and saved fixture map and
thumbnails. Private evidence and chat confirmations have no public transcript
link. Visual distinction and diagnostic sufficiency are bounded assessments;
no new live measurement or general visual-identity guarantee is claimed.
