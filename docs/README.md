For simulator work, start with the [evidence and fidelity map](reference/simulator-evidence-map.md)
and its complete searchable SDK Markdown catalog. It separates existing SDK/Qt
controls from the Buddy application simulator and links native findings to the
behavior a calibrated model should reproduce.

Read dated sections as historical checkpoints. Later evidence does not erase an
earlier refusal, and a passed host fixture, ARM cross-build or sampled controller
does not establish native lifetime, page ownership, safe mutation or compatibility.
Retain exact source/artifact revisions and source links. Proprietary firmware,
extracted source, private manifests, secrets and user content stay out of Git.

Add durable knowledge to these areas and link it from this index. Keep one canonical
body; OpenSpec retains change-specific lifecycle artifacts and links to knowledge.
Root project guidance and conventional tool-discovery files remain exceptions.
