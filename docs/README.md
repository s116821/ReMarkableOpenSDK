earlier refusal, and a passed host fixture, ARM cross-build or sampled controller
does not establish native lifetime, page ownership, safe mutation or compatibility.
Retain exact source/artifact revisions and source links. Proprietary firmware,
extracted source, private manifests, secrets and user content stay out of Git.

body; OpenSpec retains change-specific lifecycle artifacts and links to knowledge.
