## Limits and next contract work

This closes one mutation A → full request cleanup → fresh read-only B diagnostic
in one idle fixture. Native Resident/Prepared/Core, callbacks, hook and code
remain resident. No native Close, drain, cancellation, hook uninstall, module
unload or repair of the historical shutdown invalid read is established.

General repeated mutation still requires an explicit reconciliation policy and
separate qualification; this experiment deliberately refuses another mutation.
Other-writer interference, intended-target write/save/reopen, broader documents/
positions/devices and exact SDK/Buddy consumer integration remain separate work.
The adapter can live in the background while individual request resources retire;
this does not require ending a conversation or restarting xochitl per exchange.

Source basis: exact committed inputs, original native operator/actor bytes and
strict wire consumption, full archived fixture/provider/service readback, plus
the separately scoped owned and static preparation reviews. Private binaries,
document contents and raw runtime archives remain outside the repository.
